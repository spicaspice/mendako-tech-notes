Cider拡張機能の便利な使い方

Apple Music クライアントの Cider を前提に、拡張機能・テーマ・スニペット・RPC をどう使うと便利かを実用寄りで整理したメモ。

概要

Cider は Apple Music 向けのデスクトップクライアントで、2025年9月26日時点の公式サイトでは拡張性の高いカスタマイズやコミュニティ製プラグインが強みとして紹介されています。便利に使うなら、まずは Marketplace の Plugins Themes Snippets を分けて考えるとわかりやすいです。

詳細説明

1. まず覚えると楽な3分類

Cider の Marketplace には次の3系統があります。

  • Plugins: 連携機能や再生操作、表示の拡張を足す
  • Themes: 見た目全体を変える
  • Snippets: CSS っぽい軽い調整を重ねて雰囲気を整える

いきなり全部盛りにするより、最初は Theme 1つ と Snippet 少し くらいから始めるのが扱いやすいです。

2. いちばん実用的なのは「見た目の固定化」

Cider は UI をかなりいじれるので、毎日使うなら次の方向が便利です。

  • 作業用: 情報量多めのレイアウトにする
  • 集中用: ノイズ少なめのテーマにする
  • リビング再生用: ジャケットやビジュアルが映えるテーマにする

好みの雰囲気を1回作っておくと、標準アプリより「自分の再生環境」に寄せやすいです。

3. Plugins は「外部連携」と「再生操作」で選ぶ

便利さを感じやすいのは次のあたりです。

  • Discord連携: 何を聴いているかを自然に見せたいとき
  • Last.fm連携: 再生記録を残したいとき
  • 再生操作系プラグイン: キュー操作や表示切り替えを増やしたいとき
  • Visualizer系: 音楽を流しっぱなしにするときの演出強化

「見た目系」と「操作系」を1つずつ入れて、足りないものだけ増やすのが無難です。

4. Snippets は小さな不満つぶしに向いている

  • フォントサイズを少し変えたい
  • 余白だけ詰めたい
  • 色味を少しだけ落ち着かせたい
  • 一部パネルだけ強調したい

こういう用途では Snippets が便利です。Themes より軽く試せて、複数を重ねやすいのが良いところです。

5. かなり便利なのが RPC 機能

公式ドキュメントでは、Cider はローカルの RPC/API を公開できます。http://localhost:10767 で再生状態取得や再生指示ができ、トークン認証も設定できます。

  • Stream Deck や自作ランチャーから再生・一時停止する
  • ホームオートメーションやショートカットから曲送りする
  • 今流れている曲を別アプリに表示する
  • デスクトップ表示や配信用オーバーレイに再生情報を渡す

単なる音楽アプリではなく、ちょっとした自動化ハブとして使えるのが Cider の面白いところです。

6. バージョン差分は気にしたほうがいい

公式 Changelog では、2025年7月27日に 2.5.0 で Plugin support / ThemeKit / Marketplace 導入、2025年9月26日に 3.1.0 が公開されています。古い紹介記事とは画面や導線が少し違う可能性があります。

  • まず現行版で Marketplace が見えるか確認する
  • 古いブログ記事の手順は鵜呑みにしない
  • うまく動かないときは Changelog と Docs を先に見る
